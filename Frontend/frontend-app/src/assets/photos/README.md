# Photos

Copy these files from the owner's WordPress export (`wp-content/uploads/...`) into this folder,
keeping the same file names. Pages pick them up automatically on the next build; until a file is
here, the page shows a placeholder in its place.

| File | Used on |
|---|---|
| `tours_999_logo.png` | Logo in the header and footer |
| `hero.jpg` | Home page banner (any wide landscape photo, renamed) |
| `mahesh_kavinda_profile_img.jpg` | About page |
| `img_01.jpg` | About page |
| `sigiriya_img_02.jpg` | 5-day tour |
| `dambulla_01.jpg` | 5-day and 7-day tours |
| `beach_01.jpg` | 5-day and 10-day tours |
| `kandy_img_01.jpg` | 7, 8 and 10-day tours |
| `beach_02.jpg` | 7 and 8-day tours |
| `safari_img_01.jpg` | 8 and 10-day tours |
| `train_img_01.jpg` | 8 and 10-day tours |
| `nuwraaliya_01.jpg` | 10-day tour |
| `yala_01.jpg` | 10-day tour |
| `ramayana_img_001.avif`, `ramayana_img_002.avif`, `ramayana_img_003.avif` | Ramayana Trail |
| `package_01_001.jpg`, `package_02_001.jpg`, `package_03_001.jpg`, `package_004_001.jpg` | Ramayana Trail options |

Gallery photos go in `../gallery/` instead: every image in that folder appears on the Gallery page,
sorted by file name.
