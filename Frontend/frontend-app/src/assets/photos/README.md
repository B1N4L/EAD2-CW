# Photos

Photos from the Tours 999 WordPress site, resized to 1600 px wide and saved as WebP.
Pages refer to them by file name (see `src/data/packages.js`, `src/data/pages.js` and the
article files in `src/content/blogs/`), so a replacement photo must keep the same name.

To add a new photo: drop the file in this folder and use its file name in the data files.
Gallery photos go in `../gallery/` instead: every image there appears on the Gallery page,
sorted by file name.
